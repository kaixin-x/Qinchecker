QinChecker 使用帮助
===================

一、软件用途
------------
QinChecker 用于将植物 Excel 数据与 iPlant 网站中的“中国植物志（修订版，FOC）”及物种县级分布信息进行比对。

程序会先给出字段级建议，允许逐项查看、保留或编辑，再导出一份新的 Excel。原始 Excel 不会被覆盖。

iPlant 网站：https://www.iplant.cn/


二、运行条件
------------
1. Windows 10 或 Windows 11。
2. 能正常访问互联网和 iPlant 网站。
3. 基础绿色版需要电脑已安装 Google Chrome 或 Microsoft Edge。
4. 使用前先把整个 QinChecker 文件夹解压出来，不要直接在压缩包内运行 QinChecker.exe。
5. 运行软件不需要安装 Python、Excel 或 Codex；但查看导出结果需要能打开 .xlsx 文件的软件。


三、Excel 文件要求
----------------
1. 文件格式必须为 .xlsx。
2. 数据工作表名称必须为 Sheet1。
3. 第一行为表头，数据从第 2 行开始。
4. “Species”列填写拉丁学名，“物种”列填写中文名。
5. 表中必须包含下列列名，拼写应保持一致：

   Family
   科
   Species
   物种
   Lowest elevation (m)
   Highest elevation (m)
   区县
   EndemicQinling
   South/north
   Habitat
   Other occurrence
   Endemic China
   Earliest flowering
   Latest flowering
   source
   Distribution in the Qinling Moutains
   Alpine2800/2900
   备注

注意：“Moutains”是现有表格中的固定列名，请暂时不要自行改成“Mountains”。


四、开始核对
------------
1. 双击 QinChecker.exe。
2. 点击“选择 Excel”，选择需要核对的文件。
3. 设置“起始行”：填写 Excel 中准备开始处理的实际行号，最低为 2。
4. 设置“处理条数”：
   - 填 1：只处理起始行对应的一个物种；
   - 填其他数字：从起始行开始处理相应数量；
   - 填 0：从起始行一直处理到表格末尾。
5. 点击“开始处理”。

程序的搜索顺序是：
1. 先用 Species 列中的拉丁学名搜索。
2. 拉丁学名没有取得有效 FOC 结果时，再用“物种”列中的中文名搜索。
3. 如果 FOC 接受名与表格原拉丁名不同，程序提出名称修改，并在备注中记录原名与现行名称。

右下角会显示当前执行指令和正在进行的工作。超过 60 秒没有任何进度变化时，程序会自动请求停止，避免无限等待。

完成、提示及可恢复错误会显示为窗口内消息，不会弹窗打断连续复核；涉及覆盖、删除等必须由用户决定的操作仍会要求确认。


五、查看核对结果
----------------
左侧“物种目录”：
- 显示本批次中的物种和 Excel 行号。
- 字体颜色和状态文字用于区分自动就绪、待复核、失败、已确认等状态。
- 可按“全部状态、待复核、已修改、已完成、抓取失败、人工来源”筛选目录；人工文本导入的植物会显示“[人工]”标记。
- 点击“全部物种”可查看整个批次；点击单个物种只查看该物种。
- 顶部搜索框可按拉丁名、中文名或 Excel 行号筛选。

中间“字段差异”：
- 每个物种固定显示全部 17 个业务字段。
- 即使网站没有提供某个字段，也会显示该字段，并标记为待复核或抓取失败。
- “原始值”是导入 Excel 中的值。
- “来源建议”是程序依据 FOC 或县级分布得到的建议。
- “最终值”是导出时准备采用的值。
- 最终会写入且与原值不同的字段会显示为红色；保留原值、无变化或尚未确认的字段不变色。
- 选中单个植物后，植物名称、中文名和 Excel 行号固定显示在表格上方，表格会隐藏重复的“行号”和“物种”两列，为原值、新值和最终值留出更多空间。
- 双击“最终值”单元格可直接打开手动编辑窗口。

右侧“核对辅助”：
- 分为“字段来源、人工文本、执行状态”三个标签页，避免来源原文、人工导入按钮和运行日志相互挤占空间。
- 选择中间表格中的任意字段后，显示该字段的原值和新值。
- 下方只显示来源网址和网站原文。
- 点击网址可打开 iPlant 页面进行人工核对。
- 网站没有提供相应原文时，会明确显示“网站未提供该字段原文”。
- 较长网站原文默认显示摘要，点击“展开来源原文”可查看带自动换行的完整内容，再次点击可收起。

单植物人工来源文本：
- 该功能只在左侧选中具体植物时启用；“全部物种”页面不能导入，也不支持多植物批量导入。
- 右侧来源区域提供“导入文本”“查看/编辑”“重新识别”“删除文本”四个按钮。
- 导入窗口固定显示当前植物、中文名和 Excel 行号，人工文本自动绑定当前批次、工作表及该行，不需要再次匹配名称。
- 文本窗口将“FOC文本”“名称信息”“区县分布”并列显示为三栏，便于同时核对；每栏可填写来源名称、来源网址并粘贴文本，也可从 UTF-8 TXT 文件读取。至少填写一类。
- 窗口顶部按“填写文本 → 预览识别 → 应用结果”显示当前阶段；修改任何文本或来源信息后会自动回到填写阶段并要求重新预览。
- 点击“预览识别”后会显示全部 17 个字段的状态、原值、识别值和依据；只有预览成功且文本未再变化，才能“应用到当前植物”。
- 人工文本应用后会替代当前植物全部字段建议，并清除当前植物此前的接受、保留和手动编辑决定；其他植物不受影响。之后仍需在主界面逐字段接受、保留或编辑。
- 如果当前植物已有网页结果，程序会先提示人工文本将替代该植物的网页建议。
- “查看/编辑”允许修改已保存文本并重新预览应用；“重新识别”使用现有文本重新运行当前解析规则；二者都只影响当前植物。
- “删除文本”会删除当前植物的人工来源及相关决定，并从原网页缓存恢复；没有网页缓存时恢复为抓取失败状态。
- 人工来源独立保存在当前批次的 manual_sources 目录，清除网页缓存不会删除它。重新打开相同文件及相同批次范围时会自动恢复，且不会再次访问该植物网页。
- 导出的“核对日志”和说明 TXT 会明确标注人工导入来源、来源名称、网址和原文；主表仍不新增来源列。


六、逐字段操作
--------------
先在中间表格选中一个字段，再使用下方按钮：

逐字段按钮位于操作栏左侧；“全部接受、全部保留、全部恢复修改”位于同一行最右侧，只作用于左侧当前选中的植物。

1. “接受来源”
   使用网站建议值。没有来源建议的字段不能接受来源。
   默认快捷键：Alt+A。

2. “保留原值”
   放弃该字段的建议，继续使用原 Excel 值。
   默认快捷键：Alt+K。

3. “手动编辑”
   自行输入最终值，适合网站表达需要人工转换或区县需要补充的情况。
   默认快捷键：Alt+E。

4. “恢复建议”
   撤销当前人工选择，恢复程序最初给出的建议和状态。

可点击窗口顶部的“快捷键设置”修改前三项快捷键。新设置会立即生效并保存，下次打开程序仍会使用；三项快捷键不能为空或重复，也可以一键恢复默认。

完成“接受来源”“保留原值”或“手动编辑”后，程序会自动跳到下一个尚未处理的自动就绪、待复核或抓取失败字段。跳转按当前批次顺序进行，可以从一个物种直接跳到下一个物种；如果搜索条件挡住目标物种，程序会自动清空搜索条件。“恢复建议”不会自动跳转。

左侧选中单个物种时，字段操作区还会启用：
- “全部接受”：接受该物种所有尚未处理且具有来源建议的字段；网站没有建议的字段继续保留为待复核。
- “全部保留”：将该物种所有尚未处理的字段设为保留原值。
- “全部恢复修改”：撤销当前植物全部字段的接受、保留和手动编辑，恢复为网页解析刚完成时的初始建议与状态，并清除这些字段已保存的人工决定；不会影响其他植物。

“全部接受”和“全部保留”不会覆盖此前已经单独接受、保留或手动编辑的字段。批量完成后，程序会先跳到该物种仍需处理的字段；该物种全部完成后再跨物种跳转。在“全部物种”视图中，这三个按钮不会启用，需要先选择具体物种。

当“全部物种”包含超过 300 个字段时，中间表格会自动分页，每页最多显示 300 个字段，可用“上一页/下一页”查看；这不会影响跨植物跳转、复核状态或最终导出。处理完成后默认定位到第一种植物，避免一次渲染超大表格。

重要说明：
- “自动就绪”的高置信度字段会在导出时写入新表。如果不想采用，请明确点击“保留原值”或“手动编辑”。
- “待复核”和“抓取失败”的字段不会自动修改原字段。
- FOC 没有提供的内容默认保留原值，不因此直接判错。
- 每个字段可以独立处理，不需要一次接受整个物种的全部建议。


七、备注说明
------------
“备注”列不再记录普通字段的复核状态，也不记录海拔、生境、花期等普通数值变化。

备注只记录不属于简单错对判断的标准化变化，例如：
- FOC 接受名与原植物拉丁名不同；
- 植物中文名采用现行名称；
- 区县旧称转换为现行行政区名称，例如“户县→鄠邑区”。

详细复核状态、普通字段变化、待复核项、解析规则和来源仍保存在“核对日志”工作表及导出说明 TXT 中。再次处理旧版本生成的 QinChecker 复核备注时，程序会清除旧的复核详情，同时保留原有人工备注。


八、停止、恢复与超时
--------------------
1. 处理过程中可点击“停止处理”。
2. 程序会在当前网络请求安全返回后停止，已完成物种的缓存和复核结果会保留。
3. 重新打开程序并选择相同文件、相同起始行和相同处理条数，可利用已有缓存继续处理。
4. 网络缓慢、iPlant 暂时不可用或 60 秒无进度时，先导出执行日志，再重新尝试。

提速与缓存说明：
- 程序只加载文字核对所需的网页内容，会跳过图片、视频和字体，但保留脚本、接口请求及样式，县级异步分布仍会正常读取。
- FOC、名称页和县级页的实际耗时会写入实时指令和执行日志，便于定位慢在哪一个板块。
- 网站明确返回“无此数据”时，结果会缓存 24 小时，避免同一名称反复等待；网络超时、连接错误和拉丁名快速探测超时不会作为“无数据”缓存。
- 拉丁名快速探测的 12 秒是整个 FOC 探测流程的总预算；超时后会立即改用中文名继续搜索。
- 程序每处理 10 种植物会在执行日志中记录 QinChecker、Chrome/驱动子进程及合计内存。
- 每连续处理 50 次网页抓取、连续出现 2 个不完整结果，或浏览器/驱动子进程达到约 800 MB 时，程序会自动重建抓取浏览器；缓存、批次进度和复核决定不会丢失。
- HTTP 403、429、服务器 5xx、验证码和访问频繁页面会按网站异常处理，不会写成“植物无数据”；限流时不会继续追加中文名请求。
- 缓存、批次进度和人工决定采用原子写入；强制关闭造成的损坏缓存会被忽略并重新抓取。

处理正常完成后，右下角“实时进度”会显示本次完成的植物数量和总用时，同时发送 Windows 系统通知，例如“完成了 50 种植物比对，用时 126.38 秒”。如果系统通知被 Windows 关闭或当前环境不支持，完成信息仍会保留在右下角和执行日志中。主动停止或处理失败时只显示累计用时，不会发送“比对完成”通知。


九、导出结果
------------
完成查看和复核后，点击“导出核对结果”。程序会让你选择一个新的 .xlsx 文件名。

请勿选择与输入文件完全相同的路径和文件名，程序也会阻止覆盖原始文件。

一次正常导出会产生：
1. 新的 Excel 文件；
2. 与 Excel 同名的“说明.txt”文件。

新 Excel 中：
- Sheet1 保留原有列结构，不新增来源网址列；
- 本次实际修改的字段使用红色字体；保留原值的字段保持原有颜色；
- “核对日志”工作表保存字段状态、解析规则、来源网址和来源原文；
- Sheet1 的“备注”列只保存植物名称和行政区名称等标准化变化。

说明 TXT 中会列出写入数量、待复核或失败字段及相应来源网址。文件最后还会逐个植物列出已变化字段数和待复核字段数，并附具体字段名称，适合整体复核和交接。


十、导出执行日志与反馈故障
--------------------------
如果程序运行异常或无法完成任务：
1. 点击“导出执行日志”；
2. 保存生成的 TXT；
3. 记录所用 Excel 文件名、起始行、处理条数和问题发生时间；
4. 将执行日志、问题截图和出问题的示例行发给开发者。

执行日志用于定位抓取、浏览器、网络、超时和导出问题，不会在原 Excel 中新增列。


十一、常见问题
--------------
1. 提示找不到 Chrome 或 Edge
   安装最新版 Google Chrome 或 Microsoft Edge，再重新启动软件。

2. 一直显示等待或自动停止
   检查网络能否打开 iPlant；稍后重试，并导出执行日志。

3. 某个字段没有建议值
   这表示相应网站板块没有提供可直接采用的结果，或程序无法可靠解析。该字段仍会显示，请查看右侧原文后选择保留或手动编辑。

4. 县名是旧称
   程序导出时使用已配置的现行标准名，并在备注中说明变化。未收录或边缘县需要人工复核。

5. 为什么导出的数值与原表不同
   检查该字段状态是否为“自动就绪”“已接受”或“手动确认”，再查看右侧 FOC 原文和“核对日志”。

6. 能否关闭 Excel 后再导出
   建议在导入和导出时关闭正在打开的输入、输出 Excel 文件，避免文件被占用导致保存失败。


十二、数据与隐私
----------------
- 程序只读取你选择的 Excel，并访问 iPlant 获取公开植物资料。
- 输入 Excel 不会被覆盖。
- 缓存与人工复核决定保存在：%LOCALAPPDATA%\QinChecker\sessions
- 来源网址只出现在软件界面、核对日志和说明文件中，不会作为新列写入主表。

缓存管理：
- 左侧物种目录底部的“打开缓存文件夹”会直接打开网页缓存目录。
- “清除网页缓存”会先显示缓存文件数量并要求确认，只删除 iPlant 网页缓存；批次进度、人工接受/保留/手动编辑决定和 Excel 均不会删除。
- 清除后目录会自动重新创建，下次处理相应植物时重新访问网站。
- 为避免删除正在写入的文件，处理任务运行期间两个缓存按钮会暂时禁用。
